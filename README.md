## Backend

The backend is a Spring Boot Maven application generated with:

- Java 21
- Spring Boot 3.5.5
- Maven
- Dependencies: Spring Web, Spring Data JPA, PostgreSQL Driver, Validation, Spring Boot Actuator

## Next Steps

1. Open the backend project in your IDE.
2. Configure PostgreSQL locally.
3. Run the app with Maven.
4. Add security and database migration tools later after the app starts successfully.
